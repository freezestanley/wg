# Discovery

## 页面目标

- 产出一个管理后台系统中的 Agent 管理页面首版
- 支持 Agent 的查看、筛选、状态识别、基础操作与详情查看
- 未明确字段与接口先使用 mock 数据和合理假设推进

## 目标用户

- 后台管理员
- 运营 / 产品 / AI 应用配置人员

## 页面类型与受众

- 页面类型：企业后台 Agent 管理页
- 受众：需要管理多 Agent 实例、查看模型与运行状态的内部人员

## Design Read

- 页面类型 / 受众 / 风格语言 / 设计体系：企业后台 Agent 管理页 / 内部管理者 / 冷静清晰高效率 / 表格+统计+侧栏详情
- Atmosphere Layer：`none`

## 风格档位

- DESIGN_VARIANCE：low
- MOTION_INTENSITY：low
- VISUAL_DENSITY：medium-high

## 氛围层策略

- Atmosphere Layer：none
- 是否需要持续背景特效（火焰 / 粒子 / 原子 / 流体 / 光效等）：不需要
- 作用位置（仅 Hero / 局部区块 / 全页背景）：无
- 作用目标（烘托气氛 / 强化品牌 / 推动叙事 / 强化发布感）：以效率优先，不做氛围表达
- 移动端 / 低性能设备降级策略：默认静态化，无额外降级成本

## 页面方向摘要

- 当前纠偏结论：上一版更像“可视化管理展示页”，不像“真正后管平台页面”
- 后管页面应以任务效率、批量操作、字段密度、权限控制、状态处置为核心
- 主视觉策略应弱化展示感，强化工具栏、表格主工作区、批量操作、行级操作、分页与筛选
- 主要 CTA / 主行为应从“看详情”转为“筛选、定位、批量处理、进入编辑/配置”

## 审版检查点

- 首屏焦点：Agent 总览统计 + 主表格
- 首屏是否 3 秒内看出主题与主行为：是，标题/统计/表格/新增按钮同时可见
- 证明区策略（案例 / 数据 / 规格 / 信任背书）：用状态统计、调用量、成功率、最近活跃时间替代营销式证明
- 内容节奏（轻 / 中 / 强叙事）：轻，偏工具型布局
- CTA 收口方式：列表操作列 + 详情抽屉内主操作
- H5 首屏优先级：标题、关键统计、筛选入口、列表卡片首屏可见
- 明确禁止的模板味 / 竞品味：禁止营销站 Hero、夸张渐变光效、三等分功能卡片套板

## 页面结构

- 顶部页头：标题、面包屑、页面级主操作
- 主筛选工具条：关键词、状态、模型、环境、负责人、更新时间、重置/查询
- 批量操作条：批量启停、批量分配、批量删除、导出
- 主工作表格：多列高密度表格 + 选择框 + 排序 + 固定操作列
- 行内操作：编辑、配置、日志、发布记录、更多菜单
- 分页区：总数、分页器、每页条数
- 辅助区：错误提示、空状态、权限提示、操作反馈

## 风格方向

- 纠偏后改为真正后管平台风格，参考飞书后台 / 阿里云控制台 / 腾讯云控制台
- 去掉大面积 hero、强调数据卡的首页感、过强留白和装饰性卡片
- 使用更克制的页头、更紧凑的表格、更明确的边界线、真实表单控件和操作密度
- 增加控制台式区域分层：页头、筛选区、批量操作区、主表格区、分页区
- 重点信息通过字段列、状态标签、行操作和批量工具栏表达，而不是靠概览卡片主导

## 适配目标

- PC：主工作场景，完整表格 + 详情抽屉
- Pad：保留表格核心列，抽屉全屏化
- H5：降级为列表卡片，筛选折叠为抽屉/弹层

## 断点策略

- PC：>= 1200px
- Pad：768px - 1199px
- H5：<= 767px
- 以内容驱动调整表格列显隐与抽屉尺寸

## 设备使用场景

- PC：日常管理、批量查看、配置操作
- Pad：会议/巡检时快速查看状态，横屏优先，竖屏可读
- H5：仅快速查看状态、筛选、打开详情，不强调重配置

## 交互约束

- 是否允许依赖 hover：不允许依赖核心 hover
- 最小触控热区：默认不小于 `44px`
- 是否需要 Pad 横屏：需要，且横屏优先保留表格体验
- 是否需要 H5 横屏：不强依赖
- 触屏 hover 替代策略：悬浮信息改为点击详情、状态标签、更多操作菜单

## 交互补全状态

- Loading：列表骨架屏 + 统计占位
- Empty：空状态插画/图标 + 引导新增 Agent
- Error：列表区域错误提示 + 重试按钮
- Active Feedback：启停/保存后给出 toast 与按钮 loading
