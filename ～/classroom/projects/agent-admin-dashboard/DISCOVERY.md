# Discovery

## 页面目标

- 新建一个后台管理系统中的 Agent 管理页面，首版优先做到可运行、可预览、可演示。
- 让用户可快速查看 Agent 总览、运行状态、配置摘要、最近任务与快捷操作。

## 目标用户

- 内部运营、管理员、产品经理、运维协同人员。

## 页面类型与受众

- 页面类型：后台管理系统 / 数据操作页
- 受众：需要高频查看与管理 Agent 的桌面办公用户，同时兼顾 Pad / H5 快速查看与轻操作。

## Design Read

- 页面类型 / 受众 / 风格语言 / 设计体系：企业级后台、深浅对比清晰、偏专业中性、信息分层明确、弱品牌装饰。
- Atmosphere Layer：`subtle`

## 风格档位

- DESIGN_VARIANCE：`4`
- MOTION_INTENSITY：`3`
- VISUAL_DENSITY：`7`

## 氛围层策略

- Atmosphere Layer：`subtle`
- 是否需要持续背景特效：否
- 作用位置：仅头部与卡片边界细节
- 作用目标：增强精致度，不干扰读数与操作
- 移动端 / 低性能设备降级策略：全部静态化，仅保留基础 hover / active 反馈

## 页面方向摘要

- 首版页面气质：克制、专业、偏产品化
- 记忆点：左侧导航 + 顶部控制条 + Agent 列表与详情联动
- 主视觉策略：深色导航、浅色内容区、单一蓝青强调色
- 主要 CTA / 主行为：新增 Agent、启停 Agent、查看详情、搜索筛选

## 审版检查点

- 首屏焦点：Agent 总览指标 + 列表主工作区
- 首屏是否 3 秒内看出主题与主行为：是，标题、统计、搜索与新增入口同屏可见
- 证明区策略：用运行数、成功率、资源占用、最近任务体现系统可信度
- 内容节奏：中
- CTA 收口方式：顶部主按钮 + 列表行内操作 + 右侧详情快捷操作
- H5 首屏优先级：先看总览与列表，再折叠筛选和详情
- 明确禁止的模板味 / 竞品味：禁止霓虹紫蓝光污染、三等分营销卡片、过度玻璃拟态

## 页面结构

- 顶部栏：页面标题、环境标签、全局搜索、通知、管理员头像
- 左侧导航：Dashboard / Agents / Tasks / Logs / Settings
- 总览区：总 Agent 数、运行中、异常中、24h 成功率
- 筛选工具栏：搜索、状态筛选、标签筛选、排序
- Agent 列表区：名称、职责、状态、版本、最近活跃、资源占用、操作
- 详情侧栏：当前 Agent 基本信息、能力标签、健康状态、最近任务、快捷操作
- 状态区：Loading / Empty / Error / 成功反馈

## 风格方向

- 色彩：Slate/Zinc 中性色 + Cyan/Blue 单强调
- 字体：系统无衬线 + 等宽数字/状态码
- 组件：细边框、轻阴影、圆角中等、强调信息对齐与密度

## 适配目标

- PC：完整三栏信息结构，适合高频管理
- Pad：保留左侧导航收纳与详情抽屉化
- H5：单列流式布局，详情改为底部抽屉/折叠面板

## 断点策略

- `>=1280px`：桌面完整布局
- `768px - 1279px`：Pad 双栏布局，详情区改抽屉
- `<=767px`：H5 单栏布局，导航折叠，筛选可展开

## 设备使用场景

- PC：办公桌面主操作场景，查看列表、批量浏览、切换 Agent
- Pad：会议或巡检场景，以查看状态和轻操作为主
- H5：移动查看告警、状态与单条 Agent 快捷处理

## 交互约束

- 是否允许依赖 hover：仅桌面增强，不作为唯一交互条件
- 最小触控热区：不小于 `44px`
- 是否需要 Pad 横屏：需要
- 是否需要 H5 横屏：不强依赖
- 触屏 hover 替代策略：所有 hover 信息同步提供点击态/展开态

## 交互补全状态

- Loading：骨架屏覆盖指标、列表、详情
- Empty：无 Agent 时提供引导创建入口
- Error：列表加载失败时提供内联重试
- Active Feedback：按钮点击、状态切换、筛选变更均有即时反馈
