# Responsive Policy Reference

## 必须覆盖

- `PC`
- `Pad`
- `H5`

## 最少要写清

- 主要断点
- Pad 横竖屏策略
- H5 首屏优先级
- 触控热区
- hover 替代方案

## 推荐断点

- `>= 1280`：PC
- `768 - 1279`：Pad
- `<= 767`：H5

如果项目已有既定体系，跟随项目体系。

## Pad 策略

- 不能只做 PC 缩小版
- 明确横屏与竖屏的内容重排方式
- 导航、卡片列数、图片区块都要单独判断

## H5 策略

- 首屏只保留最关键的信息和 CTA
- 减少不必要的大段并列内容
- 强滚动叙事在 H5 上要降级

## hover 替代

触屏设备上，hover 相关反馈必须有替代：

- 点击态
- active 态
- 默认常显部分信息
- 或直接去掉纯 hover 才能读到的内容

## 动效降级

- `pin`、精细 `scrub`、多层视差在移动端优先弱化
- 移动端优先保留节奏，不强求保留全部动画细节
