# llm promo site

## 项目摘要

- `slug`：`llm-promo-site`
- 模板：`vite-page`
- 页面类型：单页中文品牌官网 / 落地页
- 当前占位品牌：`曜识大模型`
- 技术栈：Vite + 原生 JavaScript + Tailwind CDN + Lucide + anime.js

## 当前目标

- 交付一个可运行、可预览、可继续换品牌资产的大模型宣传官网首版。
