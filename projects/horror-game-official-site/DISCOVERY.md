# Discovery

## 页面目标

- 产出一个高完成度单页恐怖游戏官网首页，重点传达品牌世界观、压迫感氛围与电影化沉浸体验。
- 页面需具备可预览、可构建、可直接演示的前端效果，不依赖后端接口。

## 目标用户

- 喜欢恐怖、生存、叙事驱动、AAA 电影化视觉体验的核心玩家
- Steam / 主机平台潜在愿望单用户
- 内容创作者、媒体编辑、试玩活动受众

## 页面结构

1. Hero 首屏
   - 自拟游戏名 + slogan
   - 火焰 / 灰烬 / 烟雾粒子背景
   - 3D 分层标题 / 前景符号 / 深色体积光
   - 主 CTA：Wishlist / Watch Trailer
2. 游戏卖点区
   - 生存压迫、动态 AI、仪式解谜、合作/单人体验
3. 世界观 / 剧情区
   - 以电影化叙事段落展示灾厄起源与禁忌设定
4. 怪物 / 阵营区
   - 3~4 个阵营或怪物卡片，带倾斜/景深/hover 动效
5. 媒体截图区
   - 用占位画面 + 故障扫描线 + 发光边框营造宣传物料感
6. 发售平台 / CTA 区
   - 平台标签、预购 / 加入愿望单 / 社区入口
7. 页脚
   - 版权、免责声明、社媒占位

## 风格方向

- 关键词：黑暗、惊悚、余烬、仪式感、邪典、故障感、电影宣传页
- 色彩：黑 / 深红 / 焦橙 / 余烬金 / 烟灰色
- 字体策略：标题走高对比、窄体、雕刻感；正文保持可读性
- 动效策略：避免花哨杂乱，强调压迫式缓动、滚动触发、视差纵深、余烬漂浮

## Design Read（三档位）

- 保守版：暗黑视觉 + 轻量粒子 + 基础 hover
- 标准版：火焰粒子 + 3D 分层 + 滚动驱动 + 倾斜卡片
- 强化版（本次默认）：沉浸式 Hero、canvas 粒子、滚动视差、故障层、强戏剧化 CTA 反馈

## 素材 / API 策略

- 素材：默认无真实品牌素材，采用纯前端生成氛围视觉 + 占位图形块 + 自拟文案
- 图标：仅使用 Lucide
- API：本页不接真实 API，无需代理；CTA 作为展示型入口

## 适配目标

- PC：主体验设备，完整展示粒子背景、视差、3D 分层、滚动叙事
- Pad：保留沉浸式首屏与模块层级，降低视差幅度，兼容横竖屏
- H5：优先保留标题、卖点、CTA 与剧情信息，弱化重型装饰与部分 3D 位移

## 断点策略

- Desktop：`>= 1280px`，完整多层景深与横向布局
- Tablet：`768px - 1279px`，双列转单列混排，保留中等动效
- Mobile：`< 768px`，单列堆叠，首屏信息优先，减少 hover 依赖

## 设备使用场景

- PC：宣传展示、沉浸浏览、媒体截图查看
- Pad：横屏浏览宣传页、竖屏快速查看卖点与角色阵营
- H5：社媒跳转落地、快速认知品牌与点击 CTA

## 交互约束

- hover 替代：触屏设备改为点击态 / 常显态，不把关键信息藏在 hover 后
- 最小触控热区：不小于 `44px`
- Pad 横竖屏：横屏保留分层视觉，竖屏改垂直节奏与更紧凑间距
- H5 横屏：不作为主优化目标，但保证内容不溢出、不遮挡

## 核心状态补齐

- Loading：首屏粒子与资源初始化前有渐显过渡
- Empty：媒体区占位视觉可独立成立
- Error：如脚本异常，基础结构内容仍可阅读
- Active Feedback：按钮、卡片、截图、导航锚点均有明确反馈
